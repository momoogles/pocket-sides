# おぼえる台本

PDF台本をブラウザ内で読み取り、選んだ役のセリフを練習するWebアプリです。

## 開発

Node.js と pnpm のバージョンは mise.toml に記載しています。mise をインストールして、次のコマンドを実行してください。

    mise install
    mise run dev

開発中のアプリは http://127.0.0.1:5173/pocket-sides/ で確認できます。静的ファイルの生成には mise run build を使います。開発サーバーとビルドの起動時に、依存ライブラリもインストールされます。

## 使い方

1. PDFを選び、読み取り結果を確認します。
2. 文字、読み順、セリフの区切り、役名を元のPDFと照合し、必要なら修正します。
3. 練習する役とシーンを選びます。
4. 前のセリフを手がかりに自分のセリフを思い出し、「答えを確認する」で表示します。

OCRや読み順の判定には誤りが残ることがあります。練習前に元のPDFと照合してください。

## プライバシー

- PDFの読み取り、文字抽出、OCR、練習はブラウザ内で行います。PDFや台本由来の情報をサーバーへ送信せず、ログインやアクセス解析も使用しません。
- 練習を始めると、読み取り結果と設定を端末のブラウザ保存領域（IndexedDB）に保存します。保存領域は同じ配信元を使う他のアプリと共有されることがあります。共有ブラウザでは、ホーム画面から保存データを削除してください。
